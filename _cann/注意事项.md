# CANN开发注意事项
记录一下在Ascendc算子开发中遇到的一些问题，例如踩过的坑和容易出现问题的地方。

## CopyOut和LocalTensor默认值设置
现在假设在得到结果LocalTensor(**记为LocalTensor c**)计算之前，需要将输出结果**c**使用默认值清理或者复制一段内容，在计算的时候可以使用mask来控制**c**的写回。在**CopyOut**过程中，如果手动进行**Set/Wait Flag**来进行不同单元的同步，那么清空**c**需要在**CopyOut**结束，容易出错的是，误以为只要在**MTE3 -> MTE2**同步控制完成之后就可以清理，所以可能会得到如下的代码：
```cpp
Loop:
    SetFlag<HardEvent::MTE3_MTE2>(eventId);
    WatiFlag<HardEvent::MTE3_MTE2>(eventId);
    Duplicate(c,0,ELE_CNT); // clear LocalTensor c
    CopyIn();
    CopyOut();
```
这样得到的结果是错误的，原因是清理的代码运行在**vector**单元，但是**waitFlag**是在**MTE2**上进行的，所以实际上还是异步的，没有同步数据依赖。
